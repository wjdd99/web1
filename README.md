# ⏰ 벌떡 알람

알람을 끄고 다시 잠들어 지각하는 걸 막아주는 **잠 깨우기 알람 앱**입니다.
알람을 끄려면 **깨우기 미션**을 완료해야만 꺼지기 때문에, 끄는 동안 잠이 깨게 됩니다.

## 주요 기능

- **미션을 풀어야 꺼지는 알람** — 그냥 끄기 버튼으로는 끌 수 없어요
  - 🧮 수학 문제 풀기 (덧셈·뺄셈·곱셈)
  - ⌨️ 제시된 문장 그대로 따라 입력하기
  - 🔢 1~9 버튼 순서대로 누르기
  - 미션 횟수(1·3·5·7회) 선택 — 많을수록 더 확실히 깸
- **요란한 알람음** — 파일 없이 Web Audio로 생성하는 교대 경고음
- **진동** (모바일) + **화면 깜빡임** + **화면 꺼짐 방지**(Wake Lock)
- **스누즈 제한** — 허용해도 최대 1회(5분)만 가능
- **반복 요일** 설정, 여러 개의 알람 관리
- **알림(Notification)** 지원
- **PWA** — 홈 화면에 추가해 앱처럼 사용, 오프라인 동작

## 사용 방법

1. `index.html`을 브라우저에서 열기 (또는 GitHub Pages로 배포)
2. ＋ 버튼으로 알람을 추가하고 시간·미션을 설정
3. 알람이 울리면 미션을 풀어 알람을 끄기

> 📱 **모바일 팁:** 브라우저 메뉴에서 "홈 화면에 추가"를 하면 앱처럼 사용할 수 있어요.
> 알람이 정확히 울리려면 이 탭(또는 앱)이 켜져 있어야 합니다. 웹 브라우저는
> 탭이 완전히 종료되면 백그라운드에서 알람을 울리지 못할 수 있습니다.

## 기술 스택

순수 HTML / CSS / JavaScript (빌드 도구·외부 라이브러리 없음). 모든 데이터는
브라우저 `localStorage`에 저장됩니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조 |
| `style.css` | 스타일 |
| `app.js` | 알람 로직·미션·소리·진동 |
| `manifest.json` / `sw.js` / `icon.svg` | PWA(홈 화면 추가·오프라인) |
