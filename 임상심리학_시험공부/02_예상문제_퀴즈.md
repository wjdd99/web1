## PART 4. 서술형 채점 포인트
- **39.** ①규범 동조(장: 절단점·직관적 호소력 / 단: 절단점 선택·일탈 종류·문화적 상대성) ②주관적 고통(장: 스스로 평가·임상가 부담 경감 / 단: 근거 모호·고통 미보고·고통 양 결정 곤란) ③무능력·역기능(장: 추론 적음·치료 동기 촉진 / 단: 기준 설정 주체 문제·상대적·가치지향적). + 세 기준을 모두 사용하며 서로 보완.
- **40.** 의사소통(편집형 조현병 용어) / 경험적 연구 촉진(진단 기준 없으면 연구 불가) / 이상행동 원인 연구(경계선 성격장애-아동기 성학대) / 치료 효과성 근거(조현병→약물치료).
- **41.** 효능=통제된 실험·동질 내담자·내적 타당도 강조 / 효과=실제 환경 유사·이질적 내담자·외적 타당도 강조. 효능은 "치료받은 사람이 안 받은 사람보다 통계적으로 유의미하게 향상", 효과는 "임상적으로 유의미한 이득".
- **42.** 내적 타당도=효과가 오직 독립변인 조작에 의함을 증명 / 외적 타당도=결과를 여러 상황에 일반화. 내적 타당도↑를 위한 통제는 실험실 내에서만 검증되는 결과를 낳을 수 있어(외적 타당도↓) 둘 사이 균형·타협 필요. 단일 연구는 한계 → 리뷰·메타분석으로 보완.
